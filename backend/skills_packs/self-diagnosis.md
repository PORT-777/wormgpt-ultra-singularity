# Self-Diagnosis (superpowers diagnosing methodology)

When a session went wrong — repeated tool failures, a final answer
that ignored the task, or a loop that burned out — run this on
yourself.

**Protocol:**
1. Read the attempt ledger (tool, args, error, per attempt).
2. Classify the failure: bad-tool-choice / bad-args / missing-info /
   topic-drift / loop-budget. One sentence each, with the exact
   attempt number as evidence.
3. State the corrective rule you will follow next ("لا تعد نفس النداء
   الفاشل — غير الأركيومنتس أو الأداة").
4. Re-run the minimum viable version of the task under the new rule.

**Anti-patterns:** blaming the operator; vague "I will try harder";
re-running the identical failing call; hiding the failure behind a
confident-sounding summary. Evidence or it did not happen.
