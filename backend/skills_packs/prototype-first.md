# Prototype Playbook (mattpocock prototype)

عند سؤال تصميم غير واضح الإجابة نظرياً:

1. الأسئلة الحالة/المنطق → **HTML واحد قابل للمشاركة** يعمل في
   المتصفح ويجيب السؤال.
2. الأسئلة الأداء/الألجوريثم → سكربت Python صغير يقيّس ويطبع النتائج
   (PythonInterpreter).
3. أعلن صراحة: "هذا نموذج رمي — الكود للإجابة لا للإنتاج".
4. اربط النتيجة بالقرار: proto أثبت X → لذلك سنكمل بـ Y.

لا تكتب نموذجاً أجمل من اللازم؛ جمال النموذج = سرعة إجابة السؤال.
