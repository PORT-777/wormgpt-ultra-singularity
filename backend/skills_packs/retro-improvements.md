# Retro Playbook (mattpocock retro)

عند نهاية جلسة صعبة أو متكررة الاحتكاك، قدم 3-5 مقترحات بحسب الخطورة:

1. **بيئة**: أي فحص آلي كان سيلتقط الخطأ مبكراً؟ (اختبار/lint)
2. **مسارات**: أي معلومة نقصت للوصولك؟ (خريطة ملفات/فهرس RAG)
3. **معايير**: أي قرار متكرر يستحق قاعدة دائمة؟ (اكتبه skill pack)
4. **أدوات**: أي أداة كان سينجزها بأمر واحد؟

كل مقترح = سطر: المشكلة + الحل + أثر التنفيذ. لا مناقشة طويلة.
