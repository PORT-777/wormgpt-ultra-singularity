---
name: linux-computer
description: أنشئ حاسوب لينكس معزولاً وشغّل أوامر حقيقية داخله. فعّل عندما يطلب المستخدم ساندبوكس أو طرفية أو تنفيذ أمر أو بيئة لينكس مؤقتة.
---

لاستخدام حاسوب حقيقي:

1. استدعِ `port777_computer_providers` أولاً. إذا لم يكن أي مزوّد مُهيّئاً، أبلغ المستخدم بذلك ولا تتظاهر بأن حاسوباً موجوداً.
2. استدعِ `port777_computer_create` مع `mode=temporary` افتراضياً، واطلب إذناً صريحاً قبل `persistent`.
3. استخدم `port777_computer_execute` بالمعرف الذي أُرجع، وأبلغ المستخدم بـ stdout وstderr ورمز الخروج كما هي.
4. احذف الحاسوب بـ `port777_computer_delete` عند الانتهاء، أو اتركه إذا طلب المستخدم الاحتفاظ به.
5. لا تستخدم هذه الأدوات للوصول إلى بيانات أشخاص أو مواقعهم أو حساباتهم الخاصة.
