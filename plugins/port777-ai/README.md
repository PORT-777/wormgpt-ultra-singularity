# Port777 AI Platform

ربط مباشر بمنصة port777 ai من داخل محادثة Claude: فحص الحالة والنماذج، البحث في مكتبة المهارات المرجعية، وإنشاء حواسيب لينكس معزولة وتشغيل أوامر حقيقية فيها.

## الاستخدام

اسأل "هل المنصة تعمل؟" ليستخدم المهارات `platform-health` أدوات `port777_health` و`port777_models`. اطلب "ابحث عن دليل لإعداد swarm" فيُستخدم `find-playbook` للبحث في مكتبة المهارات. اطلب "افتح لي طرفية لينكس" وسيتحقق `linux-computer` من المزوّد أولاً، ثم ينشئ ساندبوكس مؤقتاً وينفّذ الأوامر ويعرض المخرجات الحقيقية مع رمز الخروج. يمكنك طلب حذف الحاسوب في أي وقت. الأوامر المباشرة تعمل في Claude Code وتظهر كمهارات تلقائية في الدردشة.

## البيانات

ترسل الإضافة أوامر المستخدم إلى خادم port777 المحلي الموضح في `.mcp.json`، ولا تُرسل أي بيانات إلى طرف ثالث. لا توجد مفاتيح API داخل الإضافة؛ المصادقة تتم على الخادم إن وُجدت. المهام والمخرجات تُخزَّن في قاعدة بيانات المنصة، والحاسوب يُحذف عند الانتهاء. استبدل العنوان المحلي بعنوان الإنتاج عند النشر مع إبقاء العنوان نفسه في ملف الدليل.
