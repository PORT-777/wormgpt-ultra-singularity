لإنشاء مهمة في port777:

1. استخرج من رسالة المستخدم: العنوان، الوصف الاختياري، الأولوية (low / normal / high)، والتصنيف.
2. اختر التصنيف من `references/task-categories.md`؛ إذا لم يناسب، استخدم `general`.
3. استدعِ أداة MCP `port777_task_create` بالحقول المستخرجة. لا تخترع معرّفاً بنفسك.
4. استخدم `port777_task_list` للتحقق من أن المهمة حُفظت.
5. ردّ بعبارة قصيرة: عنوان المهمة، معرّفها، حالتها `open`. لا تلصق الـ API response الخام.
