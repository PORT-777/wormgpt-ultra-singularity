# Task categories

| Category | Use when |
| --- | --- |
| `work` | Development, meetings, deliverables, client work |
| `personal` | Errands, home, family, health |
| `research` | Reading, investigation, benchmarks, comparisons |
| `security` | Authorized testing, hardening, incident follow-up |
| `finance` | Invoices, budgets, expense reports |
| `general` | Anything that does not fit the categories above |

Priority values: `low`, `normal`, `high`. Default is `normal`.
