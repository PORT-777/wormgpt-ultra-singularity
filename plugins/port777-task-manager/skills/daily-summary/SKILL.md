لإنشاء ملخص المهام:

1. استدعِ `port777_task_list` لجلب كل المهام، ثم مرة أخرى مع `status=open` إذا احتجت فصل المكتمل عن المعلّق.
2. رتّب النتائج: عالية الأولوية أولاً، ثم المفتوحة، ثم المكتملة.
3. اذكر العدد الإجمالي وعدد المكتمل والمعلّق، وأبرز أهم ثلاث مهام قادمة.
4. ردّ بصياغة بشرية مختصرة. لا تعرض JSON الخام ولا معرّفات داخلية طويلة إلا عند طلب المستخدم.
