# Port777 Task Manager

أنشئ مهامك وتابعها وأنجزها مباشرةً من محادثتك مع Claude عبر منصة port777 ai. يحفظ هذا الإضافة المهام في قاعدة بيانات المنصة، لذا تبقى بعد إعادة تشغيل الخادم أو تغييره.

## الاستخدام

اذكر أي عمل تريد تسجيله، على سبيل المثال "سجّل مراجعة تقرير المصاريف غداً بأولوية عالية". سيقوم المهارات تلقائياً باستدعاء أداة `port777_task_create` وحفظ المهمة. اطلب "ملخص مهامي" لعرض المكتمل والمعلّق مرتباً بالأولوية، ويمكنكقول "أنه المهمة <id>" لتحديث حالتها. الأوامر المباشرة تعمل كأوامرslash في Claude Code وكمهارات تلقائية في الدردشة.

## البيانات

ترسل الإضافة عنوان المهمة ووصفها وأولويتها وتصنيفها إلى خادم port777 عبر عنوان MCP الموضح في `.mcp.json` (`https://mcp.port777.ai/mcp`). لا تحتوي الإضافة على أي مفتاح API ولا تخزّن بيانات على جهاز المستخدم؛ كل التخزين يتم في قاعدة بيانات port777. يجب نشر هذا العنوان قبل توزيع الإضافة. للتطوير المحلي فقط، شغّل السيرفر على `127.0.0.1:3000` ووجّه إعداد Claude إليه مؤقتاً دون تعديل الملف المُرسَل.
